# Code of Conduct

Tijori follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, welcome beginners, and
keep discussions about the work. Harassment, insults and personal attacks
are not accepted anywhere in the project.

Report problems privately to the maintainers using the contact in
[SECURITY.md](SECURITY.md). Reports are kept confidential.
